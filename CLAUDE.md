# Claude Code Configuration for bounds.dev

See @AGENTS.md for complete project documentation, architecture, and guidelines.

## Quick Reference

### Development Commands

```bash
hugo --cleanDestinationDir    # Build site
make serve                    # Start Hugo dev server
make preview                  # Dev server + tailnet HTTPS link for phones
make photo-poster             # Start photo posting tool
make post SLUG=my-post        # New writing post (then follow AGENTS.md → New post checklist)
make check                    # Private hosts, GIF-hero WebPs, production build with post checks
make webp                     # Animated WebPs for GIF heroes (needs libwebp)
make sprites                  # Regenerate the committed sprite sheet from scripts/sprites.mjs
python3 scripts/compare-site-builds.py BASELINE_DIR NEW_BUILD_DIR  # Check all generated bytes
```

### Available Skills

- **smoke-test** - Verify site builds and loads (uses Playwright MCP)
- **visual-debug** - Debug frontend with browser automation

### Available Agents

- **figma-implementer** - Convert Figma designs to HTML/CSS/JS

### Permissions

Configured in .claude/settings.local.json:
- Hugo commands (version, serve, build)
- Make commands (serve, photo-poster)

## Architecture Notes

This repository uses unified AI instructions:
- `.cursor/` - Canonical source for agents and skills
- `.claude/` - Symlinks to .cursor/ directories
- `.codex/` - Symlinks to .cursor/ directories
- `AGENTS.md` - Universal project instructions
- Skills follow [Agent Skills](https://agentskills.io) standard

## Session Workflow

1. Read @AGENTS.md for project context
2. Check available skills in .claude/skills/
3. For Hugo work: remember layouts/ override pattern
4. Use agents for specialized tasks (Figma conversion)
5. Test with smoke-test skill before committing

## Hugo-Specific

- Active theme: bounds-ascii, with three site themes: light, dark (production `main.css`) and arcade (`arcade.css` + `js/arcade.js`, loaded only for arcade; see AGENTS.md); LoveIt is retained but not active and must not be edited
- Arcade only: display font Jersey 25 at 18 px and up; motion gated on `data-motion="on"` with a pause button
- Override pattern: root layouts/ take precedence over theme layouts/
- Build: Always use --cleanDestinationDir
- GitHub Pages: Hugo Extended 0.154.5; newer local Hugo currently warns about languageCode deprecation
- Server: Port 1313 (HTTP only, no HTTPS)
- Photo tool: FastAPI/Uvicorn on port 8000

For complete architecture, conventions, and patterns: @AGENTS.md
